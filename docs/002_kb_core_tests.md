# SecGraph KB Core Tests

## Назначение
Документ определяет тестовые сценарии для ядра базы знаний SecGraph.

Модуль должен корректно работать со следующими сущностями:
- kb_nodes
- kb_edges
- audit_log
- context_rules

---

# TC-01 Создание узла

Цель  
Проверить, что система может создать узел базы знаний.

Шаги
1. Отправить запрос создания узла
2. Сохранить запись в БД
3. Получить запись обратно

Ожидаемый результат
- узел существует
- тип узла сохранён
- uuid создан

---

# TC-02 Обновление узла

Цель  
Проверить изменение данных узла.

Шаги
1. Создать узел
2. Изменить поле description
3. Сохранить

Ожидаемый результат
- изменения сохранены
- версия увеличена

---

# TC-03 Мягкое удаление

Цель  
Проверить soft delete.

Шаги
1. создать узел
2. удалить через API

Ожидаемый результат
- запись не удаляется физически
- поле deleted = true

---

# TC-04 Создание связи

Цель  
Проверить связь между двумя узлами.

Шаги
1. создать узел A
2. создать узел B
3. создать связь A → B

Ожидаемый результат
- связь появляется в kb_edges

---

# TC-05 Получение связей

Цель  
Проверить получение графа связей.

Шаги
1. создать несколько узлов
2. создать связи
3. выполнить запрос графа

Ожидаемый результат
- возвращается список связей

---

# TC-06 Audit Log

Цель  
Проверить журнал изменений.

Шаги
1. создать узел
2. изменить узел
3. удалить узел

Ожидаемый результат
- каждая операция записана в audit_log

---

# TC-07 Ошибка валидации

Цель  
Проверить защиту от некорректных данных.

Шаги
1. отправить узел без типа

Ожидаемый результат
- ошибка валидации
- запись не создаётся

---

# Критерий успешного прохождения тестов

Модуль считается рабочим если:

- все тесты TC-01 — TC-07 проходят
- данные корректно сохраняются
- audit_log фиксирует изменения
- API возвращает корректные ответы
