# Information Security Risk Management — SecGraph / FATHER

Практический модуль по оценке и управлению рисками информационной безопасности для Security Business Partner / Security Architect.

> Статус: учебный прототип. Примеры **синтетические**, результаты не являются реальной оценкой риска какой-либо компании. Модуль не заявляет сертификацию или полное соответствие ISO и регуляторным требованиям.

## Цель
Проследить решение от бизнес-изменения до принятия остаточного риска владельцем:
`Business change → scope → assets → consequences → threats → risk assessment → controls → residual risk → owner decision → monitoring`.

## Принципы
1. Оценка угроз ФСТЭК и оценка **риска бизнесу** — разные, связанные этапы.
2. Шкала 1–5 и произведение L×I здесь **внутренняя демонстрационная модель**, а не обязательная формула ISO/IEC 27005 или ФСТЭК.
3. Риски оцениваются с привязкой к активам, процессам, последствиям, владельцам и доказательствам.
4. Отдельно фиксируются исходный и остаточный риски, допускаемые уровни и сроки пересмотра.
5. Решение о принятии риска принимает уполномоченный владелец риска, а не автоматически ИБ.
6. Не публикуйте в GitHub реальные топологии, уязвимости, персональные данные, коммерческие риски и внутренние оценки без разрешения.

## План
- P0: методика, критерии, образцы документов (этот набор).
- P1: автоматическая валидация реестра, контроль сроков, генерация отчёта для бизнес-владельца.
- P2: связи с графом SecGraph: asset→threat→scenario→control→risk→decision.
- P3: интеграция FATHER и CyberED, review/approval workflow, audit trail.
