# Проектное решение по ИБ № TRC-DEMO-01

**Объект:** гипотетическая программа защиты цифрового медиабизнеса на примере бренда «Триколор».

**Статус:** предварительная рекомендация независимого учебного проекта. Не согласована с компанией; не описывает реальную инфраструктуру.

## Бизнес-цель
Снизить вероятный ущерб от злоупотреблений брендом, компрометации пользовательских аккаунтов, несанкционированного использования API и сбоев цифровых сервисов, не нарушая работу легитимных пользователей.

## Альтернативы
- A «Только регламенты»: дешёвый запуск, недостаточная автоматизация при большой нагрузке.
- B «Риск-ориентированные пилоты»: минимальные контроли плюс испытание DRP/API/CI/CD на ограниченной выборке. **Предпочтительный вариант для старта.**
- C «Полный стек сразу»: возможно избыточно без данных об активах, трафике и зрелости действующей защиты.

## Решение к рассмотрению
Одобрить этап обследования и P0; сформировать базовую линию рисков и метрик; после пилота принять отдельные решения о закупках P1/P2. Не закупать продукты до подтверждения необходимости и совместимости.

## Матрица принятия решения
| Критерий | Требование |
|---|---|
| Результат | Измеримое снижение подтверждённого риска либо лучшее обнаружение/реагирование |
| Стоимость | 3–5-летний TCO, включая поддержку и кадры |
| Юридическая применимость | Права на контент, ПДн, договоры, полномочия |
| Интеграция | API, журналы, IdP, CI/CD, существующие SOC процессы |
| Эксплуатация | Ответственный владелец и достижимые SLO |
| Доказательства | Пилот, протокол испытаний, оценка остаточного риска |

## Роли
Спонсор бизнеса — бюджет и цели; бизнес-владелец — риск и последствия; ИБ — анализ и рекомендации; архитектор — совместимость; ИТ/DevOps — внедрение; юристы — законность действий с контентом и доменами.

## Следующее управленческое действие
Согласовать scope, P0 и критерии выхода на P1. Ответственных пофамильно, бюджет и сроки фиксировать только после реального обследования.
