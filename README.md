# SecGraph

**Knowledge-Driven Pentest & Security Audit Platform**

SecGraph — это платформа автоматизации аудита безопасности, пентеста и анализа инфраструктуры на основе графовой базы знаний.

## Основные модули

* Knowledge Base
* Pentest Automation
* OSINT Engine
* Security Audit
* Reporting System

## Архитектура

```
SecGraph
│
├── Knowledge Graph
├── Security Audit Engine
├── OSINT
├── Pentest Automation
└── Web Dashboard
```
